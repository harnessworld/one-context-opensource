# Changelog

All notable changes to one-context will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

The package is in **beta** (`0.x`). Until the first stable release, minor
version bumps may include manifest-format changes; the changelog documents
them here. No release has been published yet.

## [Unreleased]

### Added

- Initial open-source framework: the `onecxt` CLI (`packages/one-context`)
  with the `one_context` Python package.
- Canonical-source layout: `meta/repos.yaml`, `meta/workspaces.yaml`,
  `meta/agents.yaml`, `meta/profiles.yaml`, `.onecxt/RULES.md`,
  `knowledge/`, `skills/`, and `features/` with an index enforced by
  `onecxt doctor`.
- Tool adapters generated by `onecxt adapt`: `claude_code`, `codex`,
  `cursor` (opt-in via `--only cursor`), `hermes`, `openclaw`, `opencode`,
  and `pi`; plus a tool-neutral root `AGENTS.md`, shared
  `.agents/skills/` surface, and `adapt-report.json` compatibility matrix.
- Workspace tooling: `doctor` (consistency checks, `@`-reference
  validation, feature index closure, knowledge graph), `sync` (registry
  clones), `worktree` (per-feature git worktrees), `context export`
  (JSON/Markdown bundles with optional token-budget compression),
  `skills` runtime install/uninstall (Claude Code, Codex), and
  `smart-commit` (plan-gated multi-repo commit/push).
- Git-hook automation via `adapt-install` (post-checkout/post-merge
  regeneration, pre-commit drift prevention for canonical sources).
- Sample content: empty repository registry, `dev` workspace, seven
  generic engineering agent roles, canonical overview/conventions
  knowledge, feature templates, and one example skill
  (`skills/workspace-review`).
- Documentation: getting started, architecture, configuration reference.
- GitHub workflows and templates: CI validation matrix (Linux/macOS/Windows
  on Python 3.12; Linux also on Python 3.10), issue forms, and a PR
  template.
